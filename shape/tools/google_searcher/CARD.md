# Tool card: Google_Searcher_Tool

**When to use:** general web search for current information when no specialized database tool
fits. **When NOT:** prefer Pubmed_Searcher_Tool / ArXiv_Paper_Searcher_Tool for biomedical or
scientific literature; not an image tool. Input: a text query. Output: web search results.
