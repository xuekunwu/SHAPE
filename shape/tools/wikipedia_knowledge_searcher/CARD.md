# Tool card: Wikipedia_Knowledge_Searcher_Tool

**When to use:** look up general background/definitions from Wikipedia. **When NOT:** prefer
Pubmed_Searcher_Tool / ArXiv_Paper_Searcher_Tool for primary scientific literature; not an
image tool. Input: a text query. Output: Wikipedia article text.
