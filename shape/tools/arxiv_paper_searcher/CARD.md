# Tool card: ArXiv_Paper_Searcher_Tool

**When to use:** search arXiv for preprints/papers (methods, computational/ML literature) by
query. **When NOT:** prefer Pubmed_Searcher_Tool for clinical/biomedical literature; not an
image tool. Input: a text query. Output: matching arXiv papers/metadata.
